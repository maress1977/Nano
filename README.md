# Diplomatura en Inteligencia Artificial · Universidad Austral 2026

Material de estudio reorganizado de la diplomatura (Comisión B, abril a septiembre de 2026).

## Contenido

- [`apuntes/`](apuntes/README.md): un apunte por clase, agrupado por módulo, armado a partir de la grabación, las láminas y los notebooks de cada clase.

## Cómo se arma un apunte

Cada apunte sigue la misma estructura (en pocas palabras, conceptos clave, ejemplos, práctica, para recordar, preguntas de repaso y conexiones) para que se puedan repasar y comparar entre sí. Las fuentes originales (PDFs, notebooks y transcripciones) quedan en la carpeta local del curso y se citan al principio de cada apunte.
